เริ่มงานแบบไหน?

พิมพ์ว่าอยากได้คลิปเรื่องอะไร พิมพ์สั้นๆ หรือพิมพ์ไม่เป็นระเบียบก็ได้ บอทจะให้ AI เขียน prompt ให้ แล้วทำใน Flow ต่อเอง

ใช้ประมาณ 30 เครดิต
1เปิดแชตที่ AI เขียน prompt เสร็จแล้ว ไว้ในหน้าต่าง Chrome ของบอท (ใช้สกิล / Gem / Project ของคุณได้ตามปกติ)

มี prompt หรือคำบรรยายฉากอยู่แล้ว วางได้ทุกรูปแบบ ถ้าบอทอ่านไม่ออก จะให้ AI จัดรูปแบบให้เอง
